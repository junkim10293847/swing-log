# 스윙 로그 — 깃허브 페이지 버전

화면은 깃허브 페이지에서 열리고, 기록은 내 구글 시트에 쌓입니다.
주소가 `script.google.com`이 아니라서 구글이 붙이는 안내 띠가 나오지 않습니다.

```
브라우저 (github.io)  ──요청──▶  앱스 스크립트 (/exec)  ──▶  구글 시트
                      ◀──답──
```

## 구성

| 폴더 | 무엇 |
|---|---|
| `docs/` | 깃허브 페이지가 띄우는 화면. `index.html` 한 장과 아이콘뿐입니다. |
| `server/` | 앱스 스크립트에 붙여넣을 코드. `Code.gs`와 처음 데이터 `Seed.gs`. |

## 순서

1. **앱스 스크립트** — `server/Code.gs`를 붙여넣고 저장.
2. **배포** — 배포 → 새 배포 → 웹 앱 → **액세스: 모든 사용자** → 나오는 `/exec` 주소를 복사.
3. **깃허브** — 이 저장소의 Settings → Pages → Source를 `main` 브랜치의 `/docs`로.
4. **첫 실행** — 페이지를 열면 서버 주소를 한 번 묻습니다. 복사한 `/exec` 주소를 넣습니다.
5. **등록** — 이름과 숫자 네 자리를 정합니다.

## 접근 권한을 "모든 사용자"로 두는 이유와, 그래서 한 일

깃허브 페이지에서 보내는 요청에는 구글 로그인 정보가 실리지 않습니다.
그래서 배포를 "나만"으로 두면 화면이 서버에 닿지 못합니다. "모든 사용자"로 열어야 합니다.

열어 두면 주소를 아는 사람은 누구나 요청을 보낼 수 있습니다.
그래서 **네 자리 잠금을 서버가 직접 지킵니다.**

- 기록을 읽거나 쓰는 모든 요청은 토큰을 함께 보내야 합니다.
- 토큰은 네 자리를 맞췄을 때만 발급되고 30일 뒤 만료됩니다.
- 토큰이 없으면 서버가 한 줄도 돌려주지 않습니다. 화면 코드를 고쳐도 소용없습니다.
- 다섯 번 틀리면 잠깁니다. 틀릴수록 대기가 길어져 최대 10분입니다.
- 네 자리는 저장되지 않습니다. 소금을 섞어 2천 번 해시한 값만 남습니다.

주소를 공개된 곳에 올리지 마세요. 네 자리가 유일한 방어선입니다.

## 고칠 때

- 화면을 고쳤다 → `docs/index.html`을 바꿔 커밋. 1분쯤 뒤 반영됩니다.
- 서버를 고쳤다 → 앱스 스크립트에서 붙여넣고 **배포 관리 → 새 버전**으로 다시 배포.
